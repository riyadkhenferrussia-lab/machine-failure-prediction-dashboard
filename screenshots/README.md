# Screenshots

This folder is intentionally empty of images.

The dashboard could not be launched in the environment where the project was built (Streamlit could not
be installed there: no access to the Python package index), so **no screenshots of the running app exist**
and none were fabricated. The figures in `reports/figures/` are analysis figures generated by
`python -m src.eda` and `python -m src.evaluate`; the dashboard shows the same figures, but they are not
screenshots of it.

To add real screenshots after installing the requirements:

```bash
streamlit run app.py
```

Open <http://localhost:8501>, capture each of the four sections (Overview, Data exploration,
Model evaluation, Machine assessment), save them here as PNG files and reference them from the README.
